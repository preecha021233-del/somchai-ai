# Somchai — Complete Screen Inventory

## Primary Navigation (Bottom Nav recommended)

1. Dashboard
2. Tasks
3. Memory
4. Security
5. Owner (or more hidden under profile)

## Full Screen List

### 1. Dashboard
- System status summary
- Quick action cards (Security, Memory, Tasks, Owner)
- Recent activity feed

### 2. Security Center
- Overall security posture
- Permission Gates list (Tool Execution, Network, Memory Write, Self-Evolution)
- Recent security events / audit log

### 3. Memory Management
- Search bar
- Stats (Long-term / Working / Pending)
- Memory list with category badges
- (Future) Memory detail + edit / delete / pin

### 4. Tasks & Automation Monitor
- Active / Queued / Completed counters
- Active task list with progress
- Completed history

### 5. Owner Control Panel
- Critical toggles (Self-Evolution, Auto-approve low risk)
- Pending approval cards with Approve / Deny
- Emergency Kill Switch (high visibility, destructive)

### 6. Settings
- Appearance
- Agent Behavior
- System info & maintenance actions

### 7. States (to be fully designed next)
- Loading (skeleton + spinner)
- Empty states for each major list
- Error states with recovery actions
- Full-screen blocking error
- Notification tray / in-app banners

### 8. Supporting
- Onboarding / First-run Owner setup (future)
- Biometric / PIN lock screen
- Approval modal (bottom sheet)

---

All screens follow the same Design System and status language.
