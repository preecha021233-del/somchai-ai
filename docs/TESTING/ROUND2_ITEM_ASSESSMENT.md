## กติกาการอัปเดตผล

1. เปลี่ยนเป็น PASS ได้เมื่อทดสอบตาม prompt/เงื่อนไขของรหัสนั้นครบและมีหลักฐาน
2. ใช้ FAIL เมื่อทดสอบครบตามเงื่อนไขแล้วผลจริงไม่ตรงเกณฑ์
3. ใช้ BLOCKED เมื่อมีเหตุขัดขวางการทดสอบ; ห้ามนับเป็น PASS
4. ใช้ PARTIAL/ทดสอบบางส่วนเมื่อมีหลักฐานเพียงบางส่วน
5. เก็บผลรอบ 1 และประวัติเดิมไว้ ห้ามเขียนทับ
6. การปิด Phase 1 ต้องผ่าน P01–P43 และ device gates ที่เกี่ยวข้อง พร้อมรายงาน P53; CI ผ่านอย่างเดียวไม่เพียงพอ
